🚀 Deployment is 5 Simple Steps:

   STEP 1: Create .env.production with your Stripe secrets
            (STRIPE_SECRET_KEY, STRIPE_WEBHOOK_SECRET, MONGODB_URI, etc.)
   
   STEP 2: Launch EC2 instance (t3.medium, Ubuntu 20.04, 30GB storage)
            (Note the EC2 public IP / Elastic IP)
   
   STEP 3: Run one command:
            ./deploy-to-ec2.sh /path/to/key.pem <EC2_IP>
   
   STEP 4: Update DNS records:
            api.quranchain.com → EC2 IP
            chain.darcloud.host → EC2 IP
   
   STEP 5: Get SSL certificates on EC2:
            sudo certbot certonly --webroot -w /var/www/certbot \
              -d api.quranchain.com \
              -d chain.darcloud.host \
              --agree-tos -m admin@quranchain.com
            sudo systemctl restart nginx

Total Time: ~22-25 minutes

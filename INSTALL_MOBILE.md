# 📱 Quick Install - Mobile AI Assistant

## Install DarCloud AI on Your Phone in 3 Steps!

### Step 1: Deploy (One Command)
```bash
gh pr merge 54 --auto --squash
```

### Step 2: Set Your OpenAI API Key
```bash
wrangler secret put OPENAI_API_KEY
```
Enter your OpenAI API key when prompted.

### Step 3: Install on Phone

**iPhone/iPad:**
1. Open Safari → `https://daralnas-chatgpt.oabu77.workers.dev/assistant`
2. Tap Share button → "Add to Home Screen"
3. Name it "DarCloud AI" → Tap "Add"

**Android:**
1. Open Chrome → `https://daralnas-chatgpt.oabu77.workers.dev/assistant`
2. Tap install banner or Menu ⋮ → "Install app"

### Done! 🎉

Your always-on AI assistant is now:
- ✅ On your home screen
- ✅ Learning from every chat
- ✅ Monitoring your network
- ✅ Working offline
- ✅ Syncing automatically

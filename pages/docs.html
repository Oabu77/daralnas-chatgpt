Blockchain API

GET /health

Returns complete blockchain health including chain height, mesh peers, bridge status, compute pool, gas tolls, quantum status, and Data Ocean metrics.

curl https://blockchain.darcloud.host/health

FungiMesh API

GET /api/fungimesh/status

Combined mesh status from both layers (Node.js WebSocket + Python mesh). Returns peers, compute pool, quantum status, and Data Ocean bridging.

curl https://mcp.darcloud.host/api/fungimesh/status
GET /status

Python FungiMesh status — 340,000 nodes across 6 continents.

curl https://mesh.darcloud.host/status

AI Agent Fleet

GET /api/fleet

List all 63 AI agents with status and tier information.

curl https://ai.darcloud.host/api/fleet
GET /api/assistants

List core AI assistants with their models and endpoints.

curl https://ai.darcloud.host/api/assistants
POST /api/chat

Chat with an AI agent. Specify agent by name.

curl -X POST https://ai.darcloud.host/api/chat \
  -H "Content-Type: application/json" \
  -d '{"agent":"quranchain","message":"What is QuranChain?"}'

MCP (Model Context Protocol)

POST /mcp

MCP endpoint with 10 tools. Supports StreamableHTTP and SSE transports.

Tools: get_blockchain_status, get_fungi_mesh_status, get_data_ocean_status, get_ai_fleet_status, get_revenue_status, get_quran_verse, get_network_health, get_gas_toll_status, get_compute_pool, get_system_diagnostics

curl https://mcp.darcloud.host/.well-known/openapi.json

Revenue API

GET /api/revenue

Revenue dashboard — gas tolls, fiat payments, subscriptions, enterprise billing.

curl https://revenue.darcloud.host/api/revenue
GET /api/gas-toll

Gas Toll Highway status — 47+ monitored blockchain networks.

curl https://revenue.darcloud.host/api/gas-toll

Authentication

Public endpoints do not require authentication. For protected endpoints, include your API key:

curl -H "Authorization: Bearer YOUR_API_KEY" https://api.darcloud.host/api/...

# Product Context

QuranChain-OS is a unified AI revenue generation platform that combines blockchain technology, decentralized mesh networking, and cross-project integration to create a comprehensive operating system for distributed computing and monetization.

## Overview
The system provides a platform for AI-driven revenue generation, decentralized device networking, and blockchain-based asset management. It integrates multiple programming languages and frameworks to maximize functionality and interoperability.

## Core Features
- **Revenue Generation**: AI agents for automated business operations and Stripe payment processing
- **Mesh Networking**: FungiMesh distributed network with device auto-discovery and compute borrowing
- **Blockchain Integration**: Dual blockchain support (Node.js PoW + Cosmos SDK Go)
- **Cross-Project Bridge**: Unified control across QuranChain-OS and Project QuranChain
- **Device Management**: Auto-enrollment of discovered devices with compute power sharing
- **Multi-Language Support**: Node.js, Python, and Go services working together

## Technical Stack
- **Backend**: Node.js (Express.js), Python (Flask/FastAPI), Go (Cosmos SDK)
- **Blockchain**: Custom PoW implementation + Cosmos SDK
- **Database**: MongoDB for metadata, PostgreSQL for Cosmos chain
- **Networking**: WebSocket-based FungiMesh, HTTP APIs
- **Payments**: Stripe LIVE integration
- **Infrastructure**: Cloudflare DNS/tunneling, IPFS storage
- **AI/ML**: Python-based revenue agents and automation systems
